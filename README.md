# CodeYogi Clone

A responsive clone of the CodeYogi learning platform built using HTML, CSS, and JavaScript. This project recreates the user interface and core design of CodeYogi for learning and practice purposes.

## Features

* Responsive homepage design
* Navigation bar
* Course sections
* Hero banner
* Footer section
* Mobile-friendly layout
* Clean and modern UI

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/codeyogi-clone.git
```

2. Open the project folder.

3. Run `index.html` in your browser.

## Learning Objectives

This project was built to improve my frontend development skills, including:

* UI cloning and implementation
